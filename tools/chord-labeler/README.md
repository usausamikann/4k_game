# 同時押しパターン分類器（Draft / 4K Game）

## 使い方

ブラウザで `tools/chord-labeler/index.html` を開く。Go・Node・
Webサーバー・インターネット接続は不要（HTML + JavaScript）。
以前の単押し128件版 `tools/pattern-labeler/index.html` は変更していない。

毎拍の16分音符4位置すべてに少なくとも1ノーツを置き、そのうち
少なくとも1位置に同時押し（2〜4レーンのノーツ）を含む候補を出す。
各パターンの上下は「下=拍頭、上=拍末」。
同じ高さのノーツは同時押し。タイミングは [0,1/4,1/2,3/4]。

初期の分類ボタン：
stream-light / stream-middle / stream-dense / jack-light / jack-middle /
jack-dense / trill / one-hand trill / chord / chord-jack / chord-stream / other。

- どれかのボタンを押してからNextで1件確定。分類名の追加も可能。
- 数字キー1〜9は最初の9ボタン、EnterはNextに対応。
  10番目以降の分類はクリックで選択する。
- 「戻って修正」で直前の回答をやり直せる。
- 128件完了すると終了表示になる。
- JSON（推奨）/CSVのエクスポート、自動保存が可能。

保存先はこの分類器専用のlocalStorageキー
`4k_game.chord_pattern_labeler.v1`。前の
`4k_game.pattern_labeler.v3_1111` や `v2` の回答を変更しない。
ブラウザ・端末を変えたりストレージを消去すると失われることがあるため、
定期的にJSONとして保存すること。

## サンプルの母集団

16分音符の各位置は、レーン{D,F,J,K}の非空部分集合（15通り）。
したがって元の配置数は 15^4=50,625。

左右反転 D↔K、F↔J で同一視すると、
反転に対して不変な位置ごとの非空集合が
{DK, FJ, DFJK} の3通りあり、反転不変な配置は 3^4=81 通り。
Burnsideの補題から同値類は (50,625+81)/2=25,353。
このうち全時刻が単押しの128同値類を除いた
**25,225同値類**を「同時押しを含むリズム1111」候補とする。

全25,225件の人力分類は現実的ではないため、
`generator.js`では「同時押しのある時刻数（1〜4）」と
「最大同時押しノーツ数（2〜4）」の12層に分け、
以下の数を抽出する。総数128。

| 同時押し時刻数 | 最大2ノーツ | 最大3ノーツ | 最大4ノーツ | 合計 |
| --- | ---: | ---: | ---: | ---: |
| 1 | 24 | 12 | 4 | 40 |
| 2 | 18 | 14 | 8 | 40 |
| 3 | 10 | 12 | 10 | 32 |
| 4 | 3 | 5 | 8 | 16 |
| **合計** | **55** | **43** | **30** | **128** |

乱数seedで各層から再現可能な標本を抽出してシャッフルする。
例 `DFJ/DFJK/DFJK/FJK` の左右反転同値類は必ず1件含む。
同じseedなら同じ順序・同じ標本になるが、**seedを変更すると
標本そのものが変わる**（単押しの網羅型分類器と異なる）。

各層の数は「人力で多様なケースを観察する」ための暫定値で、
実際のランダム譜面に現れる確率や技術の難しさを反映していない。
したがって集計結果を無補正で「全25,225パターンでの出現率」と
解釈しないこと。

## 出力形式

JSONは `format="4k_game_pattern_labels"`、`version=4`、
`sampling="chords-stratified-v1"`、`rhythm_mask="1111"`、
`population=25225`、`total=128`、`sample_quotas` を保持する。

`labels[]`の各要素には回答ラベルのほか、

- `id`：左右反転で不変の `chord-XXXX` 形式ID
- `canonical_code` / `mirror_code`：4つの4bitマスクを16進4桁として扱った整数コード
- `step_masks`：各時刻の4bitマスク [1..15]。ビット0=D、1=F、2=J、3=K
- `notes_per_slot`：各時刻の同時押しノーツ数
- `chord_slots`：同時押しを含む時刻数
- `max_chord_size`：最大同時押しノーツ数
- `max_lane_run`：同じレーンに連続する時刻の最大数（レーン単位、同時押しを含む）
- `total_notes`：1拍内の合計ノーツ数
- `sampling_stratum`：サンプリング層
- `pattern` / `mirror_pattern`：ノーツ配列（`lane`, `position:[slot,4]`）

を含める。単押しのID `pattern-XXX` と衝突しないよう別の接頭辞にしている。

このツールは分類器であってゲーム本体のコードには組み込まない。
このノーツ配列をそのままゲームへ流し込む場合の同時押し処理は別途検証が必要。

## テスト

```bash
node --test tools/chord-labeler/generator.test.cjs
```

候補母集団、反転不変クラス、全12層の件数、128件の重複排除、
ノーツ形式、seedの再現性、指定例の包含をテストする。
UIの動作とダウンロードはブラウザでの受入確認も行ってほしい。
