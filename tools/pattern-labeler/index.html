4K Game / パターン分類

16分音符4スロットすべてに1ノーツずつ配置（リズム1111）。左右反転を同一視した全128パターンを分類する試作ツール。

現在のパターン

確定 0 / 128 件 #1 / 128
候補を生成中 下＝拍頭 / 上＝拍末（ゲーム中の落下方向とは逆向きの時刻配置）

このパターンの分類は？

数字キー1〜9で選択、EnterでNext。押した分類はNext時に確定する。戻ると直前の回答を修正できるよ。

記録の出力と設定

確定済みの回答をJSON/CSVで保存できる。JSONには元のパターンに加えて左右反転後のパターンも含む。

4レーン×4スロットで4⁴=256配置。左右反転で同一視した128個を重複なく提示する。seedは表示順だけを変更する。time_scaleは0固定。

自動保存はlocalStorage。端末・ブラウザを変えると引き継がれないから定期的にJSONを出力してね。70件の回答が入った旧版（v2）は別の保存領域に残す。この1111専用版（v3）は新規開始。セッションを作り直すとv3の回答は消えるよ。
