# 1拍パターン分類ツール（Draft）

tools/pattern-labeler/index.html をブラウザで開く。Go、npm、サーバー、ネット接続は不要。
ゲーム本体のコードは変更していない。

## 何を分類するか

1拍を16分音符4スロットとし、各スロットに「休符・D・F・J・K」の5種類のうち
ちょうど1種類を置く（同時押しなし）。time_scale=0固定。
全 5^4 = 625 パターンのうち、全休符は分類対象外で624パターン。
左右鏡映 D↔K、F↔J で同一視すると非空パターンに不動点がないため
624 / 2 = **312パターン**。これらの代表をすべて一度ずつ表示する。

候補の順序だけseed付き乱数でシャッフルする。候補そのものはseedによらず不変。
同一候補の左右鏡映版もJSON出力に含める。4拍子の小節や連結処理はここでは扱わない。
time_scale=1（実時間半分の圧縮）については、今回は分類対象に含めない。

## 操作

1. 下が拍頭、上が拍末の4レーン表示を見る。
2. stream-light / stream-middle / stream-dense / jack-light / jack-middle /
   jack-dense / other から選ぶ（数字キー1〜7でも可）。
3. Next（またはEnter）で回答を確定して次の候補へ。
4. 直前の回答を修正するときは「戻って修正」を使う。
5. 必要に応じて入力欄から分類を追加する。
6. 定期的に「JSONを出力」。CSVも同じ回答を表形式で出力できる。
7. 312件回答すると完了表示になる。最後の回答も戻って修正できる。

ラベルを選んだだけでは未確定。Nextで確定した回答だけをエクスポートする。
未確定の選択もブラウザに保存するため、リロード後に続きから作業できる。

自動保存先はlocalStorage（キー 4k_game.pattern_labeler.v2）。
**以前のDraft版(v1)の回答は移行しないが、v1の保存領域にはそのまま残る。**
旧版は密度・同時押し条件が異なるため、新しい312件の回答に混ぜない。
端末・ブラウザが変わるとデータは引き継がれず、ストレージ消去で失われる。
file://ページではプライバシー設定によって保存領域が変わることもある。
こまめなJSON出力を推奨。
「新しいセッション」は確認ダイアログのあと現バージョンの回答をリセットする。
分類名追加は可能だが、既存ラベルの削除・改名・JSONインポートは未実装。

## エクスポート

JSONフォーマットは 4k_game_pattern_labels version 2。
labels[]には次を含む。

- id: pattern-XXX（左右反転ペアの安定した識別子）
- seed, generator_index: 表示順の追跡
- category, labeled_at: 人手で付けた分類と確定時刻
- grid_divisions: 4固定
- canonical_code, mirror_code: 5進4桁の各スロットを符号化した整数
- pattern: 現行internal/chart互換の name, time_scale=0, notes 配列
- mirror_pattern: 同じパターンを左右反転した別のpattern

カテゴリー一覧はcategory_optionsに同梱。カテゴリ名は後から追加できる。
CSVはnotes_jsonとmirror_notes_jsonにそれぞれのノーツ配列を収める。
後の分析・再読込を考えるとJSONを主データとして扱うのを推奨。
ラベルが鏡映で不変というのが今回の前提。後で左右非対称を区別したい場合は
その前提から再検討が必要。

## テスト

Node標準のテストランナーだけで実行できる。

    node --test tools/pattern-labeler/generator.test.cjs

312件の鏡映軌道で全624パターンを覆うこと、全候補の16分時刻制約と和音禁止、
左右反転の性質、seed再現性・入力検証をテストする。
UIの見た目とブラウザlocalStorageおよび実ファイルダウンロードは
ブラウザで手動確認すること。
