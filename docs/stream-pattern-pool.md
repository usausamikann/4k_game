# 1拍streamパターンプール（生成器未実装）

## 目的と範囲

`internal/streampool` は、固定4レーンの1拍分の**候補全列挙とタグ付け**のみを行う。
ランダム抽選・BPM・パターン間の接続処理・負荷制御・複数拍の譜面生成はまだ実装しない。
過去の人力ラベリング結果には依存しない。

`streampool.Build()` で `Pool` を作成する。
`Pool.All` は実際の左右両配置を含む全454個の `Pattern`、
`Pool.ByTier[0..2]` は各tierに属するパターンの**値コピー**。
呼び出すたびに新規プールができ、生成のたびにseedが変わるような処理はない。

## 列挙条件

各拍の16分音符4時刻に、D/F/J/Kの非空レーン集合を配置する。

- D=`0001`, F=`0010`, J=`0100`, K=`1000`。
- 4つの時刻のレーン配置は `Masks[0..3]` に4bitマスクとして格納。
- 毎時刻ノーツあり（16分音符のリズム `1111`）。
- 各隣接マスクのANDは0（1拍の内部に縦連なし）。
- 通常は時刻0と2にのみ1〜3個押しを許可し、時刻1と3は単押し。
- **例外**：毎時刻2個押しの `2-2-2-2` も許可。縦連禁止を満たすもののみ。

初期の16分ストリーム向け候補：

| テンプレート（ノーツ数/時刻） | 実配置数 |
|---|---:|
| 1-1-1-1 | 108 |
| 2-1-1-1 と 1-1-2-1 | 144 |
| 3-1-1-1 と 1-1-3-1 | 48 |
| 2-1-2-1 | 72 |
| 3-1-2-1 と 2-1-3-1 | 36 |
| 3-1-3-1 | 4 |
| **通常小計** | **448** |
| 2-2-2-2（例外） | **6** |
| **合計** | **454** |

左右反転（D↔K、F↔J）の同値類数は228。
特に2-2-2-2の6配置のうち2配置は自己反転するため、
「実配置÷2」と単純には計算できない。
**生成器の接続性や左右バランスを損なわないため、
プールは左右の実配置454個を全て保持する。**
`MirrorID` と `CanonicalID` は比較・検証・将来の重複除去用のタグ。

## メタデータ

`Pattern` の公開フィールド：

| フィールド | 意味 |
|---|---|
| `Masks` | 16分音符4時刻のレーンbitmask |
| `FirstMask`, `LastMask` | 1拍の先頭・末尾 |
| `FirstTwo`, `LastTwo` | 周期2判定に使える先頭・末尾2マスク |
| `ID` | 4つのbitmaskを低位から詰めた16bit ID |
| `MirrorID`, `CanonicalID` | 左右反転IDと反転同値類の代表ID |
| `TotalNotes`, `LeftNotes`, `RightNotes` | 4スロット分の合計ノーツ数（整数） |
| `Density` | `TotalNotes/4` |
| `LeftDensity`, `RightDensity` | 左(D/F)、右(J/K)の `notes/4` |
| `BalanceDelta` | `LeftNotes-RightNotes`（整数）。将来の直近8拍queueの要素に使用可能 |
| `DensityTier` | light=0（density<1.5）、middle=1（<1.75）、heavy=2（≤2） |
| `Is2222` | 例外の2-2-2-2か |
| `Period2` | 1拍内部がA-B-A-Bの周期2配置か |
| `TrillKind` | 2-2-2-2での3種類：`jump`, `symmetric`, `asymmetric`。それ以外は空文字 |

`Period2` はストリーム内での周期2の**検出用タグ**であり、
別の拍とつないだ場合の連続長を表さない。
また `TrillKind` は2-2-2-2の種別だけであり、
片手トリルの分類タグではない。

| tier | density | 実配置 |
|---|---|---:|
| light (0) | 1, 1.25 | 288 |
| middle (1) | 1.5 | 120 |
| heavy (2) | 1.75, 2 | 46 |

heavyのうち2-2-2-2が6配置。なお、3-1-3-1の4配置は
すべて `BalanceDelta=0`。左右負荷制限だけではこれらの
周期2の連続を防げないため、後段の生成器で必要に応じて別制御する。

## 既存chartパッケージとの境界

- `Pattern.ToChartPattern()` は **1拍だけ** を既存の `internal/chart.Pattern` に変換。
  time_scale=0、ノーツ時刻は 0/240/480/720tick。
- `CanConnect(a,b)` は `a.LastMask & b.FirstMask == 0` を返す。
  拍内縦連がない候補同士の境界縦連がないことだけを保証する。
- **確率抽選、密度tier比率1:1:1、直近8拍の左右負荷queueと上限8、
  周期2/トリルの連続抑制、譜面連結は今後の設計・実装対象。**
  このPRではゲーム本体の再生動作を変更しない。
